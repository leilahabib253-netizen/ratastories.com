# RataStories

منصة عربية لكتابة القصص بالذكاء الاصطناعي + معرض قصص تجاري.

## الصفحات

- **الرئيسية** (`/`) — الصفحة التعريفية مع النص التسويقي
- **كاتبة القصة** (`/writer`) — أداة توليد القصص بالذكاء الاصطناعي
- **معرض القصص** (`/gallery`) — عرض وبيع القصص الأصلية
- **أفكار** (`/ideas`) — مكتبة برومبتات جاهزة للنسخ واللصق

## التشغيل المحلي

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

## الرفع على Vercel

1. ارفع المشروع على GitHub
2. ادخل إلى [vercel.com/new](https://vercel.com/new)
3. استورد المستودع
4. اضغط Deploy

سيحصل الموقع على رابط تجريبي مثل:
`https://ratastories-xxxxx.vercel.app`
